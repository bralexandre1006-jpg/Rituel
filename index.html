HyperOS coupe les applis en arrière-plan. Pour recevoir tes rappels à l'heure :
  1. Appui long sur l'icône Rituel, puis Infos sur l'appli.
  2. Démarrage automatique : activé.
  3. Économiseur de batterie : Aucune restriction.
  4. Notifications : autorisées, avec écran de verrouillage et pop-up.
  1. Glisse une ligne vers la droite pour la valider.
  2. Glisse vers la gauche pour la supprimer. Tu as quelques secondes pour annuler.
  3. Garde le doigt appuyé sur une ligne pour la déplacer.
  4. Dans un rappel, touche Fait pour cocher sans ouvrir l'app, ou Dans 10 min pour le reporter.
  5. Touche un rituel ou une tâche pour voir ses notes. Commence une ligne par « - » pour faire une liste.
  6. Dans Notes, la première ligne d’une note devient son titre.
