HyperOS coupe les applis en arrière-plan. Pour recevoir tes rappels à l'heure :
  1. Appui long sur l'icône Rituel, puis Infos sur l'appli.
  2. Démarrage automatique : activé.
  3. Économiseur de batterie : Aucune restriction.
  4. Notifications : autorisées, avec écran de verrouillage et pop-up.
  1. Touche le rond ou glisse une tâche vers la droite pour la valider.
  2. Glisse vers la gauche pour supprimer. Tu as quelques secondes pour annuler.
  3. Garde le doigt appuyé sur une tâche ou une étape pour la déplacer.
  4. Dans Routine, touche Commencer puis Valider à chaque étape pour passer à la suivante.
  5. Dans un rappel de tâche, touche Fait pour cocher sans ouvrir l'app, ou Dans 10 min pour le reporter.
